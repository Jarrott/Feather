# 功能与界面

## 菜单栏与截图方式

- macOS 14+，启动仅驻留菜单栏；左键区域截图，右键打开菜单与设置。
- 区域截图：默认 ⇧⌘2；支持录制 ⌘/⌥/⌃ 组合及 F1–F20，冲突保留原快捷键。
- 全屏截图：右键菜单选择，捕捉鼠标所在显示器并直接进入标注。
- 窗口截图：列出可见普通窗口的应用名和标题；选择后使用 ScreenCaptureKit 独立窗口捕捉，取消不截图。
- 重复上次区域：复用上次成功保存、复制或贴图的显示器与相对区域，每次获取新图。显示器断开时提示重新框选，不能默默截取另一屏。
- 仅持久化上次区域的显示器 ID 与归一化矩形，不保存历史截图。窗口截图不覆盖上次区域。
- 设置包含截图快捷键、保存目录、文件名模板、保存后复制、是否包含鼠标、权限入口。
- 菜单「查看更新」打开 GitHub Releases；没有后台联网检查或自动安装。

## 选区和会话

- 框选后在原位置出现绿色边框、八个调整点、像素尺寸与深色单排工具条。
- 空白处拖动移动选区，边角调整大小；选区不跨显示器。V/0 或再次点击当前工具切回移动模式。
- 选区变化迁移标注坐标；整次拖动是一条可撤销编辑。撤销/重做从同一冻结源图恢复裁剪，不复制每一步图片。
- 屏幕连接、分辨率或休眠唤醒变化：未框选时取消；编辑时保存当前手势和内联文字，保留原图与历史，等比例适配到可用屏幕。无屏幕时等待恢复。
- 编辑覆盖层保持在 screenSaver 层级；另存为面板显示在其上方。重复触发截图聚焦当前会话。
- 所有工具下双击选区内部 = ✓ = ⌘C = 主键盘回车 / 小键盘 Enter：复制带标注 PNG 并收起。选区手柄、外部和导出中不误确认。
- Esc、右键选区、× 放弃当前截图。未保存内容不自动保留；保存/复制失败时保留会话。

## 标注

| 键 | 工具 | 操作 |
| --- | --- | --- |
| 1 | 矩形 | 拖动绘制轮廓 |
| 2 | 椭圆 | 拖动绘制轮廓 |
| 3 | 箭头 | 起点拖向目标 |
| 4 | 画笔 | 拖动或点击 |
| 5 | 高亮 | 30% 透明填充，不适合遮蔽敏感信息 |
| 6 | 文字 | 在选区内原位输入，支持中文输入法和多行 |
| 7 | 遮盖 | 纯黑块替换目标像素 |
| 8 | 马赛克 | 18 原图像素块状降采样；敏感内容仍应选纯黑遮盖 |

- 工具数字键显式绑定，不依赖枚举顺序。颜色六种，线宽 2–16 原图像素，文字字号独立为 8–120 原图像素。
- 拖住轮廓、线条、文字或填充移动标注；空心区域可继续绘制，Option 跳过已有标注绘制新内容。
- 选中后 Delete / 向前删除可删除；Tab / Shift+Tab 切换选中标注，方向键移动，Shift 加速。
- 文字工具单击已有文字可重新编辑，其他工具下可选中后按 F2；单击等待双击间隔，双击仍完成截图。
- 原位文字中回车换行，⌘回车或点击外部提交，Esc 取消文字编辑；保存、复制、切换工具时先提交。文字最多 2,000 字符，超出有提示。
- ⌘Z / ⇧⌘Z 统一撤销/重做新增、移动、删除、文字修改和裁剪；最多 200 条编辑、200 个标注。
- 长笔画达到 20,000 个采样点后均匀抽稀并提示，继续记录笔尾，不静默截断。
- 马赛克不会重新暴露纯黑遮盖覆盖的源图像素；编辑辅助框、选区边框和控件不进入 PNG。

## 输出与贴图

- 保存 / ⌘S：写入默认 `~/Pictures/Feather` 或自选目录，按设置复制并收起；⇧⌘S 或保存按钮右键另存为。
- 默认文件名 `Feather_{date}_{time}_{uuid}.png`；可用 `{date}`、`{time}`、`{timestamp}`、`{uuid}`、`{width}`、`{height}`。模板拒绝路径、控制字符、未知变量；重名追加数字，原子写入且不覆盖。
- PNG 保留原始像素和源 RGB 色域（含 Display P3）；没有人工放大或 JPEG 压缩。
- 合成、CoreText 文字渲染、PNG 编码和文件写入全部在后台，界面显示导出状态并防止重复提交。剪贴板与窗口操作回到主线程。
- 剪贴板替换前完整备份原项目和类型，失败且无人接管时恢复；备份超过 64 MiB 或无法完整读取时不清空原内容。跨进程系统剪贴板不提供真正原子事务，其他应用接管后不强行覆盖。
- 贴图 / ⌘P：将完成图像钉在可拖动、缩放的浮动窗口，提供复制、保存和关闭；最多八张，退出应用即释放。
- 保存成功但复制失败分别反馈；另存为取消、导出失败、贴图上限均保留编辑内容。

## 权限、可访问性和性能

- 权限只根据实际 ScreenCaptureKit 成功/拒绝更新，未验证时显示未知；激活应用不会再用预检查 false 覆盖已知状态。
- 只在用户操作时捕捉静态帧，排除自身窗口；无后台截图流、轮询、遥测、上传或日志文件。
- 冻结原图使用 CALayer.contents，遮罩为独立形状层；动态层仅失效变化区域并跳过脏区外的标注。
- 覆盖层提供 VoiceOver 名称、说明、当前尺寸/标注与操作；工具条保留可访问名称。⌘A 可在框选阶段选全屏，方向键移动选区，Option+方向键调尺寸。
- 多屏实际插拔、不同系统窗口捕捉、中文输入法、VoiceOver 连续操作及真实屏幕帧率仍需按测试文档验收。
