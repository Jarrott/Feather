# 功能与 UI

## 菜单栏与设置
- 启动后仅显示菜单栏图标，不打开工作台，不显示 Dock 图标。
- 左键截图；右键或 Control+点击显示菜单：开始截图、偏好设置、退出。
- 偏好设置是按需创建的 560×600 原生窗口，内容超出时可滚动；关闭后释放视图。
- 设置仅包含快捷键、快速保存目录、保存后复制、是否包含鼠标和系统权限入口。
- 可录制自定义组合并保留三组预设；新组合注册成功后立即生效并持久化，失败保留旧组合。
- 录制支持 ⌘/⌥/⌃ 搭配普通键及单独 F1–F20；拒绝普通裸键、仅 Shift 的普通键和常见系统/编辑保留组合。
- Esc、点击其他位置、关闭窗口、切换应用均取消录制。原快捷键在录制期间用于结束录制，不触发截图。
- 自定义组合同步到菜单栏，重启恢复，兼容 1.0.0 预设。录制只监听当前设置窗口。
- 截图会话中禁用菜单栏设置入口；重复截图仅聚焦当前选区。

## 框选与悬浮工具条
- 用户主动截图时直接由 ScreenCaptureKit 验证授权，不以预检查 false 拦截。明确拒绝时提供系统设置、当前应用定位与重新授权/重启说明；普通错误单独展示。
- 隐藏设置后逐屏取得静态帧，排除自身窗口。
- 每屏覆盖层显示冻结画面、27% 黑色遮罩、1 点亮绿边框及带阴影的白色像素宽高；尺寸贴近选区左上边缘，靠顶时移入框内。选区不跨显示器。
- 从任意方向拖拽，最小 4×4 逻辑点。松开后在原位置显示八个调整点和悬浮工具条。
- 默认是移动模式：拖动选区内部移动；边角手柄始终可用于缩放。再次点击当前标注工具，或按 V/0，切回移动模式；数字键 1–7 始终进入对应绘图模式。
- 工具条优先放在选区下方，其次上方；空间不足时留在屏幕内部。工具条、边框和遮罩不进入导出图片。
- 主工具条固定为 48 点高的深色磨砂单排：七种标注、撤销/重做、保存/取消/完成按组分隔。悬停显示轻底色，选中工具显示绿色图标及下划线，不可用操作降低透明度；取消为红色，完成为绿色。
- 颜色/粗细使用独立小浮层，选中工具才显示。文字显示实际字号，高亮只显示颜色，遮盖显示不透明提示；导出时显示进度，失败显示错误。浮层优先朝选区外侧展开，空间不足时换侧并保持屏内，主工具条不随工具切换跳动。
- 调整选区时从同一冻结画面重新裁剪，标注保持原屏幕位置；撤销和重做中的标注同步转换坐标。超出选区的标注不导出，扩大选区可再次显示。
- 其他应用全屏空间可发起截图；显示器配置变化时取消当前会话（导出期间不打断写入）。
- Esc、右键选区、× 直接放弃截图并退出，保留菜单栏。工具条保存按钮的右键菜单用于另存为。

## 标注
| 工具 | 操作 | 导出 |
| --- | --- | --- |
| 矩形 / 椭圆 | 拖动 | 轮廓、所选颜色和粗细 |
| 箭头 | 从起点拖向目标 | 连线与实心箭头 |
| 画笔 | 连续拖动 / 点击 | 圆角线条 / 圆点 |
| 高亮 | 拖选矩形 | 30% 不透明度叠加 |
| 文字 | 点击并输入 | 原生字体，支持中文，最多 2000 字 |
| 遮盖 | 拖选矩形 | 黑色不透明替换原始像素 |

- 颜色 6 种；线宽 2–16 原图像素；文字字号为线宽的 5 倍，最小 18 像素。
- 所有工具直接在原选区操作，无独立编辑窗口；文字输入使用原生对话框。
- 最多 200 个标注，支持顺序撤销/重做；达到上限提示且保留旧标注。
- 不提供已提交标注的对象选择、移动或属性修改；可撤销后重画。选区移动属于裁剪范围变化。
- 高亮透明，不能用于遮蔽信息；遮盖应完整覆盖目标区域。

## 输出与数据
- 保存 / ⌘S：PNG 写入快速保存目录，按设置复制，成功后收起；⇧⌘S / 保存按钮右键：另存为。
- ✓ / ⌘C / Enter：复制 PNG 并收起；不会自动写入文件。
- 无损 PNG、原始像素大小、sRGB；不嵌入原图层或裁剪外图像。
- 快速保存采用毫秒时间和随机标识命名，原子写入且不覆盖已有截图。
- 另存为覆盖文件需系统保存面板确认；取消面板保留会话。
- 保存或复制失败保留选区和标注；保存成功但复制失败单独提示，保留会话供重试。
- 导出期间禁止重复输出、调整和退出，避免写入中断。
- 无历史列表，不再写入历史文件路径；旧版最近记录偏好被忽略，磁盘截图不受影响。
- 不上传、不自动删除截图、不创建日志文件，无服务器和容器。
