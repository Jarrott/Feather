# 验证与回归

## 自动化
配置固定签名身份后，一条命令完成本机验证；遇到失败立即停止，不提交或推送：

```bash
./scripts/validate.sh
```

脚本包含格式、Shell 语法、Info.plist、完整测试、Release 6K 基准、应用构建、签名与 diff 检查。GitHub Actions 仅保留手动入口，并复用该脚本。下面的命令仍可用于定位单独步骤：

```bash
swift format lint --strict --recursive Sources Tests Package.swift scripts/create-icon.swift
swift test
./scripts/build-app.sh
codesign --verify --strict dist/Feather.app
```

Swift Testing 覆盖：双向拖拽、Retina 比例、非整数像素和显示器负原点；八个手柄定位、缩放最小尺寸、移动边界、工具条屏内布局；撤销/重做和裁剪后坐标迁移；八种标注真实 PNG 渲染、上下方向、遮盖像素替换、高亮透明度；文件唯一性与无效目录；快捷键录制、校验、旧偏好兼容、注册失败保持原值及取消生命周期。

## 手动验收
每次修复后及版本升级需回归对应项。未执行的项目不能标记通过。

| 场景 | 期望 |
| --- | --- |

| 另存为取消 / 覆盖确认 | 取消保留会话，不写入；覆盖只在系统确认后发生 |

### 6K 性能基准

```bash
FEATHER_RUN_BENCHMARKS=1 swift test -c release --filter RenderingPerformanceTests
```

使用生成的 6144×3456 像素图与 20 个文字/矩形标注。一次测得：

| 指标 | 结果 |
| --- | --- |
| 后台合成与 PNG 编码 | 319.7 ms，PNG 11,149,508 字节 |
| 30 次整图 + 覆盖层离屏绘制 | 219.3 ms |
| 30 次 256×256 脏区覆盖层绘制 | 25.3 ms |

两种绘制使用相同源图与标注。该测试衡量 CPU 渲染调用，不包含窗口服务器、GPU 合成、系统捕捉、输入法或真实屏幕刷新率；数据为同机单次基准，不能当作端到端帧率或固定性能承诺。
